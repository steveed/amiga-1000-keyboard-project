# amiga-1000-keyboard-project
An open source replacement PCB for the Commodore Amiga 1000 keyboard.

![Rendered top view of the board](https://raw.githubusercontent.com/steveed/amiga-1000-keyboard-project/renders/board-top.png)

![Rendered angled view of the board](https://raw.githubusercontent.com/steveed/amiga-1000-keyboard-project/renders/board-iso.png)

Renders are regenerated by GitHub Actions whenever the board changes.

## Project Goals
1. Provide a drop-in replacement keyboard PCB for original Amiga 1000 machines.

## Controller
The board takes the original Amiga 1000 keyboard controller (a mask-ROM 6500/1). A 6570 from an
A500/A2000/A3000 keyboard also works if KCLK and KDAT are swapped: solder the cable's white and green
wires into each other's pads on J1. With the original controller: white = KCLK (PA0, pin 38),
green = KDAT (PA1, pin 37), red = +5V, black = GND.
